- Sign up at https://gumroad.com
- Create new *“Digital product”*
- Upload:
  - Pro npm package `.tgz` / zip
  - README how to install
- Set price (e.g. $19 one‑time or $9/mo)
- Enable license keys (auto)

✔ Flow:
- Buyer pays → gets license key + download link
- You verify license in Pro code (optional)

✔ Pros:
- No code backend needed
- Handles VAT, invoices

✔ Setup:

✔ Pros:
- Low fees
- Full control

✔ Cons:
- Needs server or Netlify functions for license delivery
