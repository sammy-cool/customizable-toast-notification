Comprehensive API Reference
Every option, parameter, and method exposed by customizable-toast-notification
Option Type Default Description
message string | HTMLElement "" The notification text or element body. Supports raw text or sanitized HTML.
type 'success' | 'error' | 'warning' | 'info' | 'loading' | 'custom' 'info' Semantic intent determining accessible ARIA role, SVG icon, color theme, and default sound.
duration number 2500 Display time in milliseconds before auto-dismissing. Set to 0 or Infinity for persistent manual toasts.
position ToastPosition 'bottom-right' 15 layout positions: corners, centers, edges, center-top/bottom, and top/bottom full-width.
spring boolean | SpringPreset | SpringConfig false Configures damped harmonic oscillator physics motion using modern CSS linear() curves.
animationType 'default' | 'spring' | 'bounce' | 'slide' | 'zoom' | 'fade' | 'flip' 'default' Animation entrance/exit style. Seamlessly works across standard CSS transitions and spring physics.
sound boolean | SoundPreset false Synthesizes zero-asset audio tones on toast creation via Web Audio oscillator nodes.
soundPreset 'modern' | 'retro' | 'futuristic' | 'subtle' | 'bell' 'modern' Sound design preset timbre. Easily extensible via registerSoundPreset().
showProgressBar boolean true Displays a synchronized progress countdown bar. Automatically pauses on hover.
progress number | 'indeterminate' undefined Live percentage (0-100 or 0-1) for progress streaming, or 'indeterminate' for loading shimmers.
progressBarColor string currentColor Custom color for progress bar (accepts hex, rgb, hsl, or CSS custom properties).
progressDirection 'decreasing' | 'increasing' | 'reverse' | 'ltr' 'decreasing' Progress bar fill direction (drains down by default, or fills up for uploads).
cta CTAOptions | CTAOptions[] undefined Interactive action button(s) or link. Supports multiple buttons (e.g. Accept / Decline).
undo UndoOptions | Function undefined Action undo button with dynamic decaying live countdown badge (Undo (5s)).
stacked boolean false iOS-style card deck stacking with natural scale/peek physics and hover expansion.
swipeToDismiss boolean true Enables mobile touch swipe gesture and mouse drag with spring velocity snap-back.
syncTabs boolean false Synchronizes toasts across multiple browser tabs via BroadcastChannel.
aiPrioritization boolean false Analyzes event semantics and urgency to calculate priority scores for dynamic queue ordering.
usePool boolean false High-throughput element recycling pool preventing garbage collection pressure.
showLoader boolean false Renders an inline SVG loading spinner before the message text.
loader ToastLoaderOptions { size: 14, color: 'currentColor' } Customizes spinner dimensions, stroke color, and adjacent text.
icon boolean | string | HTMLElement | Function true Controls the built-in SVG status icon or renders custom SVG / HTML markup.
showCloseButton boolean true Displays accessible '×' dismissal button with tab focus.
pauseOnHover boolean true (CTA/Undo) / false Pauses the auto-dismiss timer and freezes the progress bar on cursor hover or focus.
allowHtml boolean false Permits safe HTML elements in message string with strict XSS sanitization.
sanitizeHtml boolean true Enforces parity security sanitization (stripping dangerous scripts, styles, objects).
borderRadius string | number '50px' Corner radius for pill or modern rounded card presentation.
maxWidth string | number '400px' / '100vw' Maximum allowable width of notification container.
fontDirection 'auto' | 'ltr' | 'rtl' 'auto' Text writing direction for full bidirectional and RTL language accessibility.
wrapText 'normal' | 'truncate' | 'ellipsis' | boolean 'normal' Text display behavior: 'normal' for full multi-line text, or 'truncate' for 3-line clamp.
