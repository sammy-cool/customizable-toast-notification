API reference — live

        

          Every function this package exports, each with a working example you
          can actually run.
        


        

          
createToast(options) → Promise<ToastHandle>

          

            Returns a handle for dismissing that specific toast later —
            regardless of what else has been created since. Fire two, then
            dismiss only the first one.
          

          

            // stash the handle, dismiss it whenever you want
            const handle =
            await createToast({ message:
            "Uploading...", duration: 60000 });
            // ...later, from anywhere...
            await handle.dismiss();
          

          

            
            
          

        


        

          
toastPromise(promise, messages, options)

          

            Shows a loading toast, then swaps it for success or error once the
            promise settles — passing the real resolved value or error straight
            through.
          

          

            await toastPromise( saveData(),
            // any Promise { loading:
            "Saving...", success: (val) =>
            `Saved! id=${val.id}`, error: (err) =>
            `Failed: ${err.message}`, } );
          

          

            
            
          

        


        

          
setDefaultColors(colors) / setDefaultMessages(messages)

          

            Set your brand colors and copy once — every
            createToast({ type: "success" })
            afterward uses them automatically.
          

          

            setDefaultColors({ success: "#0f9d58",
            error: "#d93025" });
            setDefaultMessages({ success:
            "✅ Done!" });

            // no message/color needed — uses what you just set
            createToast({ type: "success" });
          

          

            
            
          

        


        

          
Smart grouping — duplicate toasts collapse automatically

          

            Same type + message + position, fired more than once, becomes one
            toast with a count badge instead of stacking.
          

          

            // fire this 3 times in a row — watch the badge, not 3 separate
              toasts
            createToast({ type: "info", message:
            "New comment on your post" });
          

          

            
          

        

      

    


    

      

        
Why not just use Sonner or react-toastify?

        

          Honestly — if you're already all-in on React, they're excellent, and
          Sonner in particular is a great default. This library exists for the
          cases those don't cover.
        

        

          

            

              Stack
            

            

              You're not on React
            

            

              Vue, Svelte, Angular, htmx, a plain multi-page app, an Electron
              shell. Every mainstream toast library assumes React. This one
              doesn't assume anything — you just saw it work with plain
              <script> tags
              above.
            

          

          

            

              Content
            

            

              Your message isn't always yours
            

            

              Show user-generated content or API error text in a toast, and
              allowHtml is
              sanitized before it touches the DOM — try the "sanitized" preset
              above.

              You want to see the tests
            

            

              129+ real Playwright end-to-end tests across three browser
              engines, zero npm audit vulnerabilities, a real semantic-release
              pipeline. Not a claim — a public repo.
