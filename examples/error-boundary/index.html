🛡️ Global Error Boundary Auto-Toast

Zero-dependency error boundary that listens for unhandled JavaScript exceptions and unhandled promise rejections, displaying non-intrusive toasts with multi-action CTAs (Copy Stack & Report).

// Wire up in your index.js / main.js entry point:
window.addEventListener('error', (e) => notifyError(e.error || e.message));
window.addEventListener('unhandledrejection', (e) => notifyError(e.reason));
